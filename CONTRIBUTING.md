# Contributing

This is an independent research repository. Issues and pull requests about the tooling, reproducibility, or the analysis are welcome.

## Rules

1. Do not submit proprietary source, prompts, or extracted bundles.
2. Keep claims reproducible: include the version, artifact hash, and the command used.
3. Run `npm test` and `npm run eval:parser` before opening a pull request.
4. Keep extracted material under `research/` (gitignored).
5. Be precise about what is observed vs inferred.

## Scope

Useful directions:

- parser and permission-gate analysis;
- compaction and context-management behavior;
- version drift between releases;
- extraction and verification tooling.

## Ethics

Keep the work technical and attributable. Do not use it to bypass a service's terms, redistribute proprietary code, or attack systems you do not own.
