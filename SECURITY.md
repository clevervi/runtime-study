# Security policy

This is a research repository, not a hosted service.

## Reporting

If you find a vulnerability in the tooling in this repository, open a private
security advisory on GitHub instead of a public issue.

Do not test findings against systems you do not own or have permission to test.
The parser evaluation runs on local fixtures only.

## Scope

In scope:

- the parser evaluation harness;
- the version-fetching tooling;
- documentation that could mislead users about safety properties.

Out of scope:

- the third-party product analyzed by the research;
- vulnerabilities that require attacking a live service.
